Un aporte de los 784
El peso fue aprendido en entrenamiento. El recuadro dorado señala este píxel en la radiografía.

Explicación completa y preparación del código
x contiene los 784 píxeles divididos entre 255. w = modelo.coef_[0] contiene los pesos y b = modelo.intercept_[0] el término independiente. Ambos se aprendieron sólo con entrenamiento. El código calcula la misma puntuación que modelo.predict_proba(x.reshape(1, -1))[0, 1].
Cada producto x[k] * w[k] aporta un término. x @ w suma los 784 productos; después se añade b. El resultado z puede ser negativo o positivo. La sigmoide 1 / (1 + exp(-z)) lo convierte en una puntuación entre 0 y 1. La regla asigna la clase 1 cuando la puntuación alcanza el umbral elegido; en caso contrario, la 0. El deslizador cambia esa comparación en validación. La evaluación de prueba conserva su umbral predefinido de 0.5.
La etiqueta de referencia aparece sólo para comparar después de predecir. Un peso o una contribución aislada no identifica una lesión ni demuestra una causa anatómica. El modelo usa class_weight="balanced"; sus puntuaciones no se han calibrado clínicamente.
Los índices de validación se refieren a la selección después de retirar copias exactas. Las imágenes se eligieron para mostrar aciertos, errores y un caso próximo a 0.5; son ejemplos didácticos, no una muestra aleatoria ni una estimación del rendimiento.

Conceptos esenciales
Lo que podemos concluir
  1. Una imagen aporta números; el entrenamiento aprende los pesos que los combinan.
  2. La validación compara opciones. La prueba evalúa las decisiones ya fijadas.
  3. Una puntuación necesita una regla para convertirse en una clase. Las métricas usan distintos denominadores.
  4. Este ejercicio no valida un diagnóstico: la resolución, la procedencia, la independencia por paciente y la evaluación externa importan.
Autoevaluación: ¿qué cambia al mover sólo el umbral?
Cambian las clases predichas y la matriz de confusión. Las puntuaciones y los pesos permanecen iguales. En el ejemplo ficticio, un umbral más bajo clasifica más casos como 1: puede reducir FN y aumentar FP. El umbral de prueba del modelo real permanece en 0.5.
