# Figuras del taller

Estas figuras ilustran cortes cerebrales, matrices, histogramas, contraste, curvas de nivel, ruido, filtros y bordes en los materiales del taller.

El [cuaderno de imágenes médicas](../Taller_imagenes_medicas.ipynb) explica las operaciones con ejemplos y controles. La [guía visual](../Guia_visual_imagenes_medicas.pdf) contiene ejemplos adicionales con numeración propia.

Las imágenes cerebrales derivan de la plantilla pública MNI152. La matriz de juguete y las perturbaciones artificiales se construyen con código. Consulta [FUENTES_Y_LICENCIAS.txt](../FUENTES_Y_LICENCIAS.txt) para conocer su procedencia.
