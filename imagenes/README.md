# Figuras del taller

Estas 23 figuras muestran los resultados del cuaderno: cortes cerebrales, matrices, histogramas, contraste, curvas de nivel, ruido, filtros y bordes.

Puedes reproducirlas ejecutando [Taller_imagenes_medicas.ipynb](../Taller_imagenes_medicas.ipynb). Sus explicaciones y ejercicios están en la [guía visual](../Guia_visual_imagenes_medicas.pdf).

Las imágenes cerebrales derivan de la plantilla pública MNI152. La matriz de juguete y las perturbaciones artificiales se construyen con código. Consulta [FUENTES_Y_LICENCIAS.txt](../FUENTES_Y_LICENCIAS.txt) para conocer su procedencia.
