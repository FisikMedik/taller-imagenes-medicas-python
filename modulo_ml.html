De radiografías a predicciones

Un primer modelo de aprendizaje automático

Juan Calderón · Módulo opcional del taller de imágenes médicas · ML Honduras 2026

Estas imágenes tienen una etiqueta de referencia. ¿Puede un programa aprender de unos ejemplos y clasificar otros que no utilizó para ajustar sus pesos?

Radiografías pediátricas de PneumoniaMNIST, reducidas por sus autores a 28 × 28 píxeles. Los rótulos son etiquetas del conjunto; no son una interpretación médica hecha en este taller.

Ejecutar y experimentar

Ejecuta las celdas de arriba abajo con Mayús + Enter, usando CPU. Después mueve los controles junto a los gráficos: se actualizan al soltar el deslizador. También puedes escribir su valor numérico. Si cambias un valor inicial en el código, vuelve a ejecutar esa celda.

Los controles necesitan una sesión de Python activa; las imágenes guardadas permiten leer el cuaderno sin ejecutarlo. Si reinicias la sesión, ejecuta de nuevo desde el principio.

Entrenamiento aprende pesos; validación elige C; prueba evalúa con decisiones fijas. El umbral del informe será 0.5. Los controles de exploración no cambian ese informe.

Es un ejercicio educativo con datos públicos: las etiquetas y puntuaciones no sustituyen una evaluación médica. El conjunto no permite comprobar independencia por paciente.

1D · Localizar o descargar los datos públicos

if not ruta.exists():
    ruta.parent.mkdir(parents=True, exist_ok=True)

    ruta.write_bytes(contenido)

Bloque 4 · Cómo una suma se convierte en puntuación

La regresión logística aprende un peso por característica y un término independiente. Su suma es z; la sigmoide la transforma en puntuación. Por ejemplo, 0.2×1 + 0.8×(−1) + 0.6 = 0: la sigmoide devuelve 0.5.

4A · Elegir sumas para explorar

np.linspace(-6, 6, 400) construye 400 valores igualmente espaciados entre −6 y 6. Representan sumas posibles, todavía no imágenes. .size cuenta elementos y [0], [-1] leen el primero y el último.

Código del paso 4A
z = np.linspace(-6, 6, 400)
print("Valores de z:", z.size, "· desde", z[0], "hasta", z[-1])

Salida guardada · paso 4A

Valores de z: 400 · desde -6.0 hasta 6.0

4B · Transformar las sumas con la sigmoide

La sigmoide es 1 / (1 + exp(-z)). np.exp calcula la exponencial para todos los valores de z. El signo menos invierte la suma; sumar 1 y dividir transforma cualquier suma en una puntuación entre 0 y 1. min, max y round resumen el rango mostrado.

Código del paso 4B
p = 1 / (1 + np.exp(-z))
print("Rango de puntuaciones:", round(float(p.min()), 6), "a", round(float(p.max()), 6))

Salida guardada · paso 4B

Rango de puntuaciones: 0.002473 a 0.997527

4C · Ver la curva y sus ejemplos

Cambia «Suma z»: el punto se mueve sobre la curva y el texto muestra la cuenta.

plot(z, p) dibuja la sigmoide. exp(-suma_z) calcula la puntuación del punto elegido. scatter marca ese punto; annotate escribe su valor. axhline dibuja la referencia horizontal de 0.5. FloatSlider permite decimales y interactive vuelve a ejecutar ver_sigmoide con cada cambio. El control explora la función, no entrena un modelo.

Código del paso 4C
def ver_sigmoide(suma_z=0.0):
    fig, ax = plt.subplots(figsize=(9, 4.4), layout="constrained")
    ax.plot(z, p, color="#007f89", linewidth=3)
    punto = 1 / (1 + np.exp(-suma_z))
    ax.scatter(suma_z, punto, color="#c96932", s=85, zorder=3)
    ax.annotate(f"z={suma_z:.1f} → {punto:.3f}", (suma_z, punto), xytext=(8, 14), textcoords="offset points")
    ax.axhline(0.5, color="#697887", linestyle="--")
    ax.set(title="Sigmoide: mueve la suma y observa su puntuación", xlabel="Suma z", ylabel="Puntuación", xlim=(-6, 6), ylim=(-0.03, 1.12))
    plt.show()
    print(f"1 / (1 + exp(-({suma_z:.1f}))) = {punto:.6f}")
    return fig

suma_control = widgets.FloatSlider(value=0.0, min=-6.0, max=6.0, step=0.1,
                                  description="Suma z", continuous_update=False)
visor_sigmoide = widgets.interactive(ver_sigmoide, suma_z=suma_control)
display(visor_sigmoide)

Salida guardada · paso 4C

1 / (1 + exp(-(0.0))) = 0.500000

Bloque 5 · Una regla de referencia

Antes de entrenar un modelo, medimos qué consigue una regla que siempre predice la clase mayoritaria. Superarla es una primera comparación, no una prueba de utilidad clínica.

5A · Ajustar la regla mayoritaria

DummyClassifier(strategy="most_frequent") crea una regla que siempre responde con la clase más frecuente. fit(X_train, y_train) averigua cuál es esa clase usando entrenamiento. Este modelo sirve de referencia mínima: no aprende patrones de los píxeles.

Código del paso 5A

referencia.fit(X_train, y_train)
print("Referencia ajustada únicamente con entrenamiento.")

Código del paso 5B

5C · Medir la referencia

accuracy_score divide aciertos entre total de imágenes. balanced_accuracy_score promedia el porcentaje reconocido dentro de cada clase. .2% muestra una proporción como porcentaje con dos decimales. La segunda medida evita que la clase más abundante oculte a la otra.

Código del paso 5C
base_val = [accuracy_score(y_val, pred_base_val), balanced_accuracy_score(y_val, pred_base_val)]
print(f"Exactitud {base_val[0]:.2%} · equilibrada {base_val[1]:.2%}")

Salida guardada · paso 5C

5D · Comparar las dos medidas

11B · Elegir el primer ejemplo de cada casilla


& exige que referencia y predicción coincidan con la casilla buscada. flatnonzero obtiene sus índices. Si hay alguno, candidatos[0] elige el primero, sin buscar una imagen favorable. El diccionario relaciona la sigla con ese índice.


Código del paso 11B
